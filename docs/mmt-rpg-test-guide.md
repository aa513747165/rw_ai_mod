## 1. 历练系统（CompPawnProgress）

依据：`mmt-rpg-design.md` §2.1 + `mmt-class-design.md` §9.3；代码 `Source/MyModeTest/Progression/PawnProgress.cs`、`TalentXPPatches.cs`。

### 1.1 XP 来源逐项验证

选中任意殖民者 → 人物面板「历练」页签（ITab_Pawn_Progress）观察 XP 进度条。逐项触发并确认 XP 上涨（数值 × 设置 `xpMultiplier`）：

| 来源 | 操作 | 预期 XP |
|---|---|---|
| 造成伤害 | 用枪/近战攻击训练假人或敌人 | 伤害 × 0.1 |
| 击杀 | 击杀人类/虫/机械 | 人类 10 / 虫 8 / 机械 15，按 combatPower 分档加成（2→160），Boss 200 |
| 技能学习 | 让小人不间断工作自然涨技能 | 技能经验 × 0.2 |
| 工作完成 | 手术 25 / 治疗 18 / 制作·研究·烹饪 8 / 采矿 6 / 建造·收获 4 / 搬运 2 / 清洁 1 | 按档（同一人 60 tick 冷却，连续同类工作不会每次都跳） |
| 品质产出 | 制作一件高品质物品 | 糟糕 2 → 传奇 75 递增 |
| 社交/贸易/招募/捕获 | 聊天、与商队交易、招募囚犯、捕获敌人 | 2 / 15 / 38 / 捕获时 12 格内殖民者各 6 |
| 灵能释放 | 有灵能的小人施放灵能/职业技能 | 5 + 熵耗，钳制 3–50 |
| 熵累积/集中消耗/冥想 | 冥想、使用集中类能力 | 有 XP（2500 tick 冷却节流，不刷屏） |

- **dev 快验**：Dev 刷一个敌人 → 击杀看击杀 XP；制作台 god mode 秒做一件传奇品质物品看品质 XP；调设置 XP 倍率到 2.0 后重复上面任一项，确认翻倍。

### 1.2 升级与被动

- 曲线：N→N+1 需 `100×N^1.5`（1→2 约 100，10→11 约 3160），上限 60 级。
- 每级 +1 天赋点，升级弹出消息「历练提升到 N 级，获得 1 点天赋点」。
- 每级被动（Hediff `MMT_PawnProgress`，20 档封顶）：WorkSpeedGlobal +1%/级（20 级 +20%）、MoveSpeed +0.5%/级（20 级 +10%）。
- **验证**：升到 2 级后查看小人属性页（Gear/Stats），全局工作速度与移动速度有对应上浮；升到 20 级后再升级，属性不再变化（成长移交天赋树），但天赋点照常 +1。
- **历练书**（副本奖励消耗品）：右键「研读」→ +500 XP/本（堆叠多本按本数乘算）。对非人类/无 comp 小人使用无效果无报错。
- **dev 快验**：Dev→发放历练书或直接用「天赋点 +10」反向验证等级（天赋点随等级发放，读 ITab 数字）。

### 1.3 设置项（Mod 设置面板）

| 设置 | 默认 | 验证 |
|---|---|---|
| 历练/职业总开关 pawnProgressEnabled | 开 | 关闭后：攻击/工作不再涨 XP；天赋树 gizmo 与「历练」页签隐藏；既有历练 Hediff/等级保留（重新打开后恢复显示） |
| XP 飘字 xpGainMotes | 关 | 打开后获得 XP 时头顶飘「+N 历练」文字；关闭则无 |
| XP 倍率 xpMultiplier | 1.0（0.1–5） | 调 0.5 → 各来源 XP 减半 |

### 1.4 存档兼容

- 读档后 XP/等级/天赋点不丢失；旧存档（无 comp）小人静默跳过、无红字。
- 总开关关闭再读档：数据保留，无红字。

## 2. 职业系统与天赋树

依据：`mmt-class-design.md` §2/§3/§5/§9；代码 `PawnClass.cs`、`TalentTreeDef.cs`、`TalentTreeWindow.cs`、`ClassAbilityEffects.cs`、`SummonTurret.cs`。

### 2.1 天赋树窗口（TalentTreeWindow）

入口：选中小人 → gizmo「天赋树（可用 N 点）」（有可用点时出现）或「历练」页签内「打开天赋树」按钮。

逐项验收 UI：

| 项 | 操作 | 预期 |
|---|---|---|
| 树页签 | 左侧切换「通用树 / 各已解锁家族树」 | 未就职时只有通用树；就职后出现本家族树页签 |
| 画布平移 | 右键拖拽 | 画布跟随平移 |
| 缩放 | 滚轮（朝鼠标位置缩放） | 0.35–2.0 倍之间缩放，连线与节点同步 |
| 节点详情 | 单击节点 | 右侧详情显示名称/效果文本/花费/前置，底部显示剩余天赋点 |
| 连线绘制 | 缩放/平移后观察 | 连线在画布边缘正确裁剪，无穿帮线条 |
| 双击链式解锁 | 双击一个远处未解锁节点 | 沿最短路径逐节点检查门禁并一次性扣点解锁到该节点；点数不足或门禁不满足时中止并提示 |
| 洗点 | Debug「天赋全退」 | 全部节点退回、天赋点返还、技能 gizmo 移除、被动 Hediff 摘除 |

### 2.2 加点与门禁

- 通用树（59 节点，战斗/灵能/生产/生存/社交五支）：
  - Dev「天赋点 +10」→ 从 Start 向外逐节点解锁；被动节点解锁后属性立即生效（如采矿速度节点 → 属性页 MiningSpeed 上浮）。
  - 未连通节点置灰不可点；`requireAllConnected` 节点需多个前置全满足。
  - 点数不足时按钮置灰显示缺口。
- 家族解锁 Keystone（五支末端，cost 3，ClassUnlock）：
  - 点出后该家族状态变为已解锁（详情/导师台菜单可见）；未点出前导师台对应职业菜单项显示「未解锁」。

### 2.3 就职

前置：建职业导师台 `MMT_ClassMentorBench`（2×2，微芯片×6 + 钨钴合金×40 + 强化玻璃块×60，WorkToBuild 6000，800W，需通电）。

- 步骤：Dev「发放职业凭证×1」给小人（凭证在背包/身上）→ 历练 ≥5 级 → 右键导师台 →「就职·法师系…/就职·斗士系…」→ 选已解锁家族的职业 → 小人走过去执行短仪式。
- 预期：
  - 消耗凭证 ×1；获得职业 I 阶 Hediff（健康页不显示为疾病）；家族树 Start 节点自动免费解锁；I 阶技能以 gizmo 出现（下方技能栏）。
  - **无灵能链接的小人就职时自动觉醒 1 级灵能**（检查灵能页签出现等级 1）；已有灵能者不重复提升。
  - 未满足条件时菜单项为灰字提示（未通电 / 历练不足 / 未携带凭证 / 未解锁家族），逐项反测。
  - 每人限 1 职业：已就职小人右键导师台只显示升阶分支，不再出现就职菜单。

### 2.4 升阶

| 目标阶 | 历练要求 | 材料（随身携带） |
|---|---|---|
| I（就职） | ≥5 级 | 职业凭证 ×1 |
| II | ≥20 级 | 能量结晶 ×10 |
| III | ≥35 级 | 能量结晶 ×20 |

- 步骤：小人带足结晶 → 右键导师台 →「<职业> → II/III 阶」→ 仪式完成后：低阶 Hediff 摘除、高阶 Hediff 添加；家族树中 requireTier=2/3 的技能节点与强化节点变为可解锁。
- 预期：升阶不重复扣凭证；结晶数量不足菜单显示缺口；阶位被动数值随阶位提升（如游侠射击精度 ×1.03→×1.06→×1.10）。
- 技能解锁路径：家族树技能节点消耗天赋点解锁 → 技能 gizmo 出现（阶 Hediff 本身不再授予技能）。

### 2.5 技能抽测（按效果桶，覆盖 37 职业前先抽代表）

以下每个桶至少抽 1 个技能实战验证（对训练假人/敌人/友军施放，观察特效、数值、冷却、熵/集中消耗）：

| 效果桶 | 代表技能（职业） | 验收点 |
|---|---|---|
| 投射物 LaunchProjectile | 燃烧之箭（火法） | 命中点燃；投射物贴图正确 |
| 区域伤害 AoEDamage | 火焰风暴（火法 III） | 范围轰炸/脉冲区伤害 |
| 治疗 Heal | 圣光术（圣骑士） | 治 3 处伤+止血 |
| 召唤 Summon | 召唤仆从（召唤师） | 仆从出现干活、限时 Hediff 到期自动消失 |
| 召唤建筑 | 魔法防御塔（召唤师） | 限时炮塔攻击敌人，到期消失 |
| 位移 Teleport | 闪烁（奥术法师） | 自身瞬移到目标格 |
| 突进 DashStrike | 相位突袭（刀锋舞者） | 位移+落点伤害 |
| 心灵控制 MentalState | 恐惧支配（恶魔术士） | 目标及旁观者陷入恐慌 |
| 群体增益 GiveHediffAoE | 战斗之曲（吟游诗人） | 范围内友军获得 buff |
| 维持光环 ToggleAura | 内心之火（火法）/ 指挥官三光环 | 开启后驻留 Hediff、按脉冲间隔（默认 300 tick）续期；熵到上限自动关闭；再次点击手动关闭 |
| 天气 SpawnEffect | 唤雨者（冰法 III） | 降雨开始/停止 |
| 复活 ResurrectLite | 英雄不朽（牧师 III，600s 冷却） | 刚死未腐尸体复活、双方虚弱数日；腐尸不可用 |
| 个案：改写命运 | 时空法师 | 死亡回溯生效 |
| 个案：尸爆 | 死灵法师 | 尸体延时爆炸 |

- 灵能消耗规则：小技 熵 8/集中 1%，中技 16/2%，大招 35/4%（个别技能映射表覆盖）——施放后检查灵能页签熵与集中变化；冷却与 RoM 一致（秒级显示在 gizmo tooltip）。
- 同名分级合并技能（如各职业 I–IV 同名技）效果随阶位缩放（I ×0.8 / II ×1.0 / III ×1.25）——I 阶与 III 阶各放一次对比数值。
- 维持光环性能：连续开启 3 个以上光环观察游戏速度；设置 `classAuraInterval` 调大后脉冲变稀（低配降载手段）。

### 2.6 品质暴击（MMT_Perk_Masterwork 节点）

- 通用树生产支节点（原第 19 perk 并入）：解锁后制作成品 10% 概率品质 +1 档。
- 验证：设置 `classQualityCritEnabled` 开 → 批量制作 20+ 件物品，统计出现高于正常发挥的品质；关闭设置后不再出现。

### 2.7 凭证获取闭环（非 dev 途径）

- A 级以上公会委托奖励职业凭证 ×1（见 §3.1）；职业凭证碎片 ×3 在装备强化台配方 `MMT_CraftClassToken` 合成 1 凭证（碎片产自职业圣殿据点，见 §4.3）。

### 2.8 旧档迁移（TalentTreeUtil.Migrate，幂等）

- 用职业系统 v1（19 perk 时代）或更早的存档加载：
  - 旧 perk 自动映射为通用树节点（不扣点），剩余 perk 点 1:1 转天赋点；
  - 已就职小人免费补发家族树 Start + 当前阶位全部应得技能节点（技能不丢，gizmo 仍在）；
  - 重复读档不重复补发（幂等）；无红字。

## 3. 任务系统

依据：`mmt-class-design.md` §9.4、`mmt-rpg-design.md` §3.3；代码 `GuildQuest.cs`、`RpgQuestChain.cs`。

### 3.1 公会狩猎委托（本地段 F–D）

- 触发：Dev「生成公会狩猎委托」，或自然等待（默认间隔 1 天，设置 0.5–5；新档/读档后半个间隔出第一张）。
- 段位判定：按全殖民者历练水平（均值与最高×0.75 取大）+ 财富（每 25 万 +1 上限，至多 +2）。新档低历练时应出 F–D 段。
- 本地委托（F–D）验收：
  - 收信「公会狩猎委托（X 级）」，信件注明段位/奖励/期限 7 天；
  - 目标生物在殖民地边缘刷出：动物为永久猎杀状态主动袭人，虫类挂虫族派系；F–E 1 只、D–C 2 只；
  - 全部击杀 → 「委托完成」信 + 白银空投 + 战斗图上的殖民者均分 XP（60×2^rank，F=60、E=120、D=240）；
  - 期限 7 天超时不杀 → 委托失败信。

### 3.2 公会委托（世界段 B–SSS）与据点联动

需要较高历练/财富的存档（或用 Debug 把历练拉高后生成）。

| 段位 | 形式 | 验收点 |
|---|---|---|
| B / A | 世界站点群猎（4 / 6 只，距家 2–8 格，15 天过期） | 世界地图出现「狩猎场（X 级委托）」；远征/传送进入后目标在图中心 30 格内刷出；全灭 → 完成，奖励含能量结晶 2–6（B 以上）；A 段另有**职业凭证 ×1** |
| S–SSS | 站点单 Boss（combatPower ≥220） | 同上，目标为单只强敌 |

- **据点联动（既有据点）**：先用扫描仪扫出一处未清剿据点放着，再生成世界委托 → 委托应挂载该据点（信件措辞「公会核实了你们扫描发现的据点…」）；清剿该据点 → 委托完成 + 据点战利品 + 委托报酬**双份收益**；空投落在据点图（站点已移除则回退殖民地）。
- **直建新副本**：无既有据点时约 35%（`guildQuestDungeonChance`）直建新副本（信件措辞「公会侦测到一处新据点…」），段位映射档位 B→I / A→II / S+→III；其余回退自建狩猎场。可多次生成观察两种措辞都出现。
- **失败路径**：世界委托 14 天超时 → 失败；联动据点被超时移除且未曾在图上见过敌人 → 失败（「据点信号消失」）；见过敌人后全清或站点被移除 → 成功。
- 设置：关闭公会委托总开关（talentQuestsEnabled）后不再自然生成（Debug force 仍可）。

### 3.3 任务链「远古军械库」

依据 `mmt-rpg-design.md` §3.3；触发门控：设置 `rpgQuestsEnabled` + `bossEncountersEnabled` 双开。

- **触发（二选一）**：
  - 深空扫描完成时 20% 概率（反复扫描刷触发）；
  - 财富 ≥15 万后每日 10% 判定。
- **第一幕 信号截获**：触发后收信，世界地图标注一处试炼场据点（II 档系数）。
- **第二幕 试炼收集**：任务页签实时显示职业凭证碎片进度 x/3；碎片来源 = 家园地图储存区 + 殖民者背包 + 远行队货物（试炼场/职业圣殿可重复刷）。可用 Dev 刷 3 个碎片放储存区快进此幕。
- **第三幕 守卫巢穴**：碎片凑齐 → 生成 Boss 巢穴据点（威胁 ×2.0）→ 进图清剿（见过敌对威胁后全清，或站点被移除）→ 空投传说装备 ×2（tier 3，大师~传奇）+ 职业凭证 ×1 + 远古数据核心 ×2 → 结局信。
- 完成/失败后进入 **30 天冷却**，冷却后可再次触发（重复验收一遍）。
- **关闭任一开关**后不再触发；进行中的链不受开关影响。

## 4. 副本/据点系统

依据：`mmt-dungeon-design.md`；代码 `Exploration.cs`、`Dungeon.cs`、`DungeonBlueprint.cs`、`BossSummoner.cs`。

### 4.1 三档深空扫描

前置：研究「深空扫描」→ 建扫描仪（蓄电 30000 Wd，3000/天 回充；地图上有矿物声纳模块）。

| 档位 | 声纳模块 | 扫描天数系数 | 威胁系数 | 装备品质地板 |
|---|---|---|---|---|
| I 浅层扫描 | ×1 | ×1.0 | ×1.0 | 精良~稀有（Good~Excellent） |
| II 深层扫描 | ×2 | ×1.5 | ×1.6 | 稀有~史诗（Excellent~Masterwork） |
| III 全域扫描 | ×3 | ×2.0 | ×2.5 | 史诗~传说（Masterwork~Legendary） |

- 验收：蓄电满后 gizmo「启动深空扫描」弹出 **FloatMenu 三档选档**（非单按钮）；模块不足时对应档位提示缺口；模块数/天数 × 设置 `dungeonTierCostFactor`（0.5–3）。
- 启动 → 清空蓄电 + 扣模块 → 扫描倒计时（装超频模块 +10%/个提速，最多 5）→ 完成收信 → 世界地图出现据点（距家 6–30 格，30 天过期）。
- **威胁公式**：`clamp(财富/100, 800, 5000) × 类型系数 × 档位系数`——同存档分别扫 I/III 档，进图对比守卫数量/强度差异。
- 据点池权重：稀有资源点 28 / 轨道遗迹 22 / 机械据点 12 / 试炼场 22 / 职业圣殿 16 / Boss 巢穴 4（≈3.8%，受 bossEncountersEnabled 门控）。多次扫描（或 Dev 重扫）观察各类据点都出现；关闭 bossEncountersEnabled 后 Boss 巢穴不再入池。
- 旧档兼容：旧存档扫描出的据点无档位信息，按 I 档处理，不会误发高档奖励。

### 4.2 据点布局与守卫（SitePartWorker_MMT_Dungeon）

进图逐项验收：

- 布局要素：外墙围合 + 1–2 处入口、独立奖励库房（墙+门）、守卫哨位（沙袋/掩体±炮塔）、照明点缀；Boss 巢穴中央留开阔巢位。
- **Boss 池化生成（巢穴）**：进 Boss 巢穴图应在中央巢位看到 1~3 只 Boss 级单位——候选来自原版/Mod 全库（isFighter 且战力 ≥150）+ XML 白名单，按财富预算抽选（预算 = 威胁点 × 0.5）：低财富档出弱 Boss/单只，高财富档出强 Boss 或多只；类人 Boss 挂宿主派系随守卫行动，机械/虫/异常实体挂各自派系，动物系强制永久狂暴。极低财富抽不出 Boss 时静默退化为大型守卫据点（不报错）。
- 守卫：宿主派系 PawnGroupMaker 产出（约 70% 威胁预算），挂 `LordJob_SitePawns` 驻守、受击后转反攻；防御工事（约 30% 预算）挂宿主派系，敌意走原版。
- 炮塔供电：需电炮塔由原版 GenStep_Power 自动接发电/电池/电缆，进图确认炮塔在线。
- 派系自适应：宿主为 mod 派系时（装一个含敌对派系的 mod 验收），墙体材质取守卫装备采样材料，炮塔优先同 mod 包（权重 ×3）且不超过派系科技水平。
- 回退链（静默无红字）：敌对派系枚举为空 → 机械集群守卫；无 Royalty → 无守卫纯奖励点；炮塔扫描无命中 → XML 白名单 → 纯沙袋哨位。
- **跨 Mod 兼容验收**：加装含敌对派系/炮塔的 mod → 副本中出现该 mod 单位与建筑；卸载该 mod 后新据点正常回退、旧档无红字。

### 4.3 奖励验收

- 奖励堆在据点奖励库房/内部，沙袋围圈标记；按档位核对构成：

| 档位 | 装备箱 | 材料 | 消耗品 | 凭证类 |
|---|---|---|---|---|
| I | 精良~稀有随机词条装备 ×1 | 远古合金 ×10~15 | 历练书 ×1 | — |
| II | 稀有~史诗 ×1~2 | 远古合金 ×8~12 + 远古碎晶 ×4~6 | 历练书 ×1~2 | 凭证碎片 ×1~2（职业圣殿必出） |
| III | 史诗~传说 ×2 | 远古碎晶 ×6~10 + 远古合金 ×5~8 | 历练书 ×2 | 凭证碎片 ×2~3（职业圣殿必出） |

- 装备箱词条：检查装备 label（「前缀·装备名 +N」）与检查面板（强化等级 + 附魔词条列表）；品质符合档位地板；词条与武器类型匹配（近战限定词条不出现在枪上，反之亦然）。
- 第二条奖励线：击杀守卫掉落的装备同样带随机强化/附魔（与袭击者规则一致）；拆工事可回收材料。
- 凭证碎片合成：3 碎片 → 装备强化台配方 `MMT_CraftClassToken` → 职业凭证 ×1。

### 4.4 玩家副本蓝图（DungeonBlueprint）

- **捕捉**：建筑师菜单「副本蓝图」→「保存为副本蓝图」→ 框选一片已建成建筑（单边 ≤40，含炮塔/门/墙/用电设备）→ 命名弹窗保存；重名触发覆盖确认。
- **管理**：Mod 设置【副本蓝图】→ 列表显示缩略图（炮塔红/门黄/墙灰/用电橙/其它蓝灰逐格绘制）+ 据点类型开关 + 档位开关（I/II/III）+ 删除；缩略图与实际布局一致。
- **生成接入**：蓝图勾选「试炼场 + I 档」→ Dev 反复扫 I 档直到出试炼场（或用委托直建）→ 进图确认布局 = 蓝图（炮塔挂宿主派系、奖励散布内部、需电建筑已接电）；取消全部勾选或删除蓝图 → 回退程序化布局（静默无红字）。
- **跨存档**：蓝图存全局设置，换存档仍在；「恢复默认设置」不清除蓝图。

### 4.5 Boss 召唤器（dev 测试工具）

- 仅在 Dev 模式建造菜单可见「MMT_BossSummoner」（关闭 Dev 后从菜单消失）。
- 建造后 gizmo 列出 Boss 候选（XML 白名单 ∪ 全库 isFighter 且 combatPower ≥150，标注战力与来源包，含其它 mod 的 Boss 级单位）→ 选目标格 → 敌对生成：机械挂机械族派系、类人挂敌对派系 + 立即进攻、动物/实体永久狂暴。
- 用于验收：高强度战斗压力测试、公会 S 段委托目标、任务链 Boss 战演练。

## 5. 已知边界与注意事项

- **Boss 为池化选取**：巢穴 Boss 来自「XML 白名单 ∪ 原版/Mod 全库扫描」按财富预算抽选（可多只），不是固定单位；MMT 自建的远古守卫者（`MMT_BossAncientGuardian`）尚未实装，为白名单预留位，实装后自动入池。验收时不要预期看到特定 Boss，而应核对 Boss 战力与据点威胁大致匹配。
- 职业技能音效暂用原版灵能施法音；导师台/召唤建筑贴图为 RoM 占位（待 AI 生成专属贴图）。
- 薄职业（附魔师/时空法师/傀儡师等）技能较少属设计现状；deferred 清单见 `mmt-class-design.md` §4。
- CE 共存时远程弹道被重写，部分投射物类技能/远程强化数值可能失效（不声明 CE 依赖）。
- 维持光环是全套系统唯一持续 tick 开销：低配机器少开光环或调大 `classAuraInterval`。
- 公会委托为自动接受制（无拒绝按钮）；任务链双开关只拦新触发，不影响进行中的链。
- 公会委托/任务链的完成检测均为 250 tick 节流驱动，清剿后最多约 4 秒延迟才弹完成信，属正常。

## 6. 回归基线（每轮手测前执行）

- `dotnet build Source/MyModeTest/MyModeTest.csproj` 零错误。
- `PYTHONIOENCODING=utf-8 python tools/validate_new.py all` 全绿，重点套件：`pawn_progress`（历练 20 stage 连续/stat 引用）、`rom_classes`（37 职业技能引用/RoM 全集核对）、`talent_tree`（图连通/唯一 Start/cost 规则/家族覆盖）、`rpg_quests`（档位表/据点池/奖励池/布局白名单/配方/任务链引用）、`exploration`、`dungeon_blueprint`、`loot_roll`（词条池分组）、`enemypools`。
- `python tools/validate_mod.py all` 旧链回归全绿。
- 旧存档加载无红字（迁移幂等）；终局包功能（强化台/扫描仪旧路径/奇点）不受影响，参照 `docs/mmt-endgame-test-guide.md` §8。
