# MMT 武器手册（战斗数值）

- 由 `tools/build_mmt_weapons_doc.py` 自动生成（改 Def 后重跑）；MMT 数据源 `1.7/Defs`，HSK 数据源 `Hardcore-SK/Mods/Core_SK`（只读参考）。
- DPS 口径：tick=1/60 秒；爆发 DPS=伤害×连发数÷((连发数-1)×连发间隔)，单发武器不适用（—）；持续 DPS=伤害×连发数÷(预热+冷却+连发窗口)。近战 DPS=Σ(伤害/冷却×概率)÷Σ概率。
- 制造配料链见 [mmt-weapon-chains.md](mmt-weapon-chains.md)；本手册重数值。
- 第 2 部分 HSK 武器为 CombatExtended 口径（伤害在弹药上、有弹匣/换弹），与 MMT 的原版式数值不直接可比，仅作移植参考清单。
