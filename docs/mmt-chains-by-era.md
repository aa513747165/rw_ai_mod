# MMT 生产链路：按时代整理（中世纪 / 工业 / 电气 / 太空 / 未来）

- 数据来源：`1.7/Defs` 实际 Def（研究点数/前置/解锁取自 `ResearchProjectDefs`，配方前置取自 `RecipeDefs`，建筑前置取自 `ThingDefs_Buildings`）。
- 本文为手写整理文档，非脚本生成物；改动 Def 后请人工同步。
- 分类口径（经确认的映射，非原版 techLevel 直译）：
  - **中世纪**：Neolithic + Medieval 研究的手工/燃烧类链（不耗电）。
  - **工业**：Industrial 研究中的燃料/机械链（无电力前置、建筑不耗电）。
  - **电气**：Industrial 研究中带 `Electricity`/`MicroelectronicsBasics` 前置、或解锁电动建筑的链（电动升级版）。
  - **太空**：Spacer 研究的链。
  - **未来**：Ultra + Archotech 研究的链。
- 每条链按「研究（点数）→ 解锁建筑 → 核心产出流向」书写；`[原版]` 表示前置/建筑来自原版。

## 一、中世纪（Neolithic / Medieval，手工时代）

> 特征：全部不耗电，靠手工台与燃烧窑；是落地前期的生存层。

### 1. 木材链
- 木工加工 `MMT_Woodworking`（Neo, 300）→ 手工锯台 → 木板/柴火/竹板/红木板
- → 木炭烧制 `MMT_CharcoalBurning`（Med, 500）→ 窑炉 → 木炭（后续金属冶炼与发电的燃料基础）

### 2. 农业链
- 农业 I `MMT_AgricultureBasic`（Neo, 150）→ 堆肥/肥料/土堆（土堆是混凝土链的原料之一）

### 3. 药用植物 & 医疗链
- 药用植物 I → II（Neo, 150/200）→ 芦荟、中性花播种
- 医疗物资 I → II（Neo, 150/200）→ 手工制药台 → 粗制绷带/绷带包
- → 医疗物资 III → IV（Med, 400/500）→ 草药包、基础医药包、肾上腺素

### 4. 毒品链（早期段）
- 毒株种植 I → II → III（Neo, 100/150/200）→ 卷烟/雪茄/咖啡
- 毒品 I `MMT_Drugs_A1`（Neo, 75）→ 晾晒架 → 烟叶晾晒

### 5. 玻璃链
- 玻璃制造 `MMT_Glassworking`（Med, 300，前置 [原版] Stonecutting）→ 玻璃制作台 → 玻璃生料 → 玻璃块
- 配套：制砂手工配方（[原版] Stonecutting）；手动采石机（[原版] Stonecutting）产粗矿石

### 6. 金属链（熔炉段）
- 基础金属冶炼 `MMT_BasicMetalworking`（Med, 800，前置 [原版] Smithing）→ 熔炉
  → 铜/锡/青铜/钢铁/铅/银/金 + 陶瓷/粘土砖/铁滤网（滤网 → 筛矿链耗材）

### 7. 义肢链（原始段）
- 义肢制造 I（Med, 300）→ 原始假肢工作台 → 眼罩/钩手/玻璃眼等原始假肢

### 8. 武器（古代段）
- 古代武器配方挂原版研究：Greatbow / RecurveBow 等（弓、弩类）

## 二、工业（Industrial，燃料/机械时代）

> 特征：研究达到 Industrial，但以燃料、手压、手动机械为主；不依赖电网。

### 1. 石化链
- 基础石化工艺 `MMT_BasicPetrochemistry`（1200，前置 [原版] BiofuelRefining）
  → 石化产品实验室 + 手压油泵 → 原油 → 聚合物 → 塑料/合成橡胶/人造纤维/碳聚物
- → 高级石化工艺（1500）→ 石蜡/硫酸盐/碳纤维锭/复合粘剂/表面活性剂

### 2. 混凝土链
- 混凝土技术 `MMT_ConcreteBasic`（1000，前置 [原版] Stonecutting）→ 手动混凝土搅拌器
  → 土堆（农业链）+ 碎石 → 混凝土 → 钢筋混凝土

### 3. 金属链（精炼段）
- 高级金属精炼 `MMT_AdvancedMetalRefining`（1600）→ 镍/钴/铬合金、梅尔基奥合金（喂给太空时代的高级合金）

### 4. 玻璃链（强化段）
- 强化玻璃工艺（1500，交叉前置：基础石化工艺）→ 强化玻璃

### 5. 零件链
- 零件加工 `MMT_ComponentCrafting`（600）→ 手工装配台 + 电动装配台
  → 原始零部件（木板/金属）→ 普通零部件/机械组件/电线

### 6. 电子链（后段）
- 集成电路技术（2000）→ 集成电路/微芯片
- → 人格核心合成（2500）→ 伪人格核心

### 7. 医疗/义肢链（工业段）
- 医疗物资 V（800）→ 医疗注射炮台
- 义肢制造 II → III（1000/1000）→ 假肢工作台；义肢安装 II → IV（800/800/1100，[原版] Prosthetics/VitalsMonitor 前置）

### 8. 毒品链（工业段）
- 毒品 V（1000，[原版] DrugProduction）→ 中性胺精炼厂 → 中性胺（天然/石化两条路线）→ 止痛药
- 毒品 VI（900）

### 9. 武器链（常规段，全部挂原版前置 + MMT 进阶）
- 枪械 II（1600，[原版] Blowback/GasOperation）→ 步枪 II（1100）→ 步枪 III（1200）
- 发射器 I（1200，[原版] HeavyTurrets）；火箭弹 I（1400）；手榴弹 I → II（700/700）
- 炮塔：重机枪塔（700，[原版] GunTurrets）→ 重型炮塔 II（1200，[原版] SniperTurret）
- 艺术用品（400）→ 染料/绘画用品

## 三、电气（Industrial + 电力，电动化升级时代）

> 特征：仍是 Industrial 研究，但前置含 [原版] Electricity / MicroelectronicsBasics，或解锁电动建筑；是中世纪/工业链的"通电升级"层。配套电源：原煤发电机（2500W，[原版] Electricity）。

### 1. 电动木材：电动木材加工（1500，[原版] Microelectronics）→ 电动锯木台/电动木炭窑
### 2. 电动金属：电弧冶炼（2000，[原版] Microelectronics）→ 电弧炉
   - 对比熔炉：铜/锡/铅 10→20 个/炉，产量翻倍，并新增铝、斯特合金、金属罐、硅提取
### 3. 电动石化：电动石化工艺（1800，[原版] Microelectronics）→ 电动石化实验室（电蒸馏聚合物等）
   - → 高级石化工艺（1500）→ 聚合物发电机（5000W，烧聚合物；煤电 2500W 与核电 20000W 之间的过渡档）
### 4. 电动电子：基础电子工艺（1600，[原版] Microelectronics）→ 电子器件工作台（提硅/电子元件）
   → 电动电子工艺（2200）→ 同台电动化提产
### 5. 电动混凝土：混凝土 II（1000）→ 电动混凝土搅拌机
### 6. 矿粉链（本时代的核心新链）
- 矿粉筛选 `MMT_OreSifting`（800，[原版] Stonecutting + Electricity）→ 电动采石机/电动研磨机/电动筛子
  → 粗矿石 → 矿粉 → 筛出随机矿石（OreSiftPool 按权重覆盖全矿种）
- → 自动化矿料处理（2000，[原版] Microelectronics）→ 矿料进料口 + 自动研磨/筛/采石机（无人值守）
- → 自动机增效（2500）→ 超频/并行/矿产增值模块
### 7. 研究设备：研究终端（600，[原版] Microelectronics）→ 多元分析仪（1200，需高级研究台）→ 实验站（2000）
### 8. 毒品 III（300，[原版] PsychoidBrewing）→ 电动晾晒架

## 四、太空（Spacer，高科技时代）

> 特征：需要高级研究台与多元分析仪支撑；解锁大功率电力、高级材料与太空武器。

### 1. 材料链
- 高级合金 `MMT_AdvancedAlloys`（2300）→ 钨/钛/司太立/镍钛/钨钴/钛铁/贫铀/斯坦/亚力可合金
- 高级零件（1600）→ 高级零部件/先进机械组件/矿物声纳模块（含护盾腰带、伪人格核心拆解）
- → 超级零件（2500，交叉前置：高级合金）→ 自动化装配器 → 超级零部件/磁性材料/生物合成材料/生物电子元件
- → 精密筛分（1800，交叉前置：高级合金）→ 精密滤网
- 氧化燃料（2500）→ 氧化化合燃料（石化链终点）
- 超织物工艺（2000，[原版] AdvancedFabrication）→ 超织物

### 2. 电力链
- 核能发电 `MMT_NuclearPower`（4000）→ 核能反应堆（20000W，燃料棒由铀在电动电子工艺台组装）
- → 能量聚能 `MMT_EnergyConvergence`（4000）→ 能量聚能发电站 + 点火充能装置 → 能量结晶
- 过渡档：聚合物发电机（5000W，烧聚合物）由电气时代的高级石化工艺解锁，见电气章

### 3. 物质/机器人链
- 物质转换 I（2500，交叉前置：零件加工）→ 无机物转化器 → 生物质提取/无机物转化
- 机器人工程 I（2000）→ 动力电池/机器人部件

### 4. 医疗/义肢链（太空段）
- 医疗物资 VI（2000，[原版] MedicineProduction）→ 闪耀世界医药
- → 战地医疗装备（2000）→ 治疗炮塔（2500）→ 小型治疗炮塔
- 义肢安装 V → VIII（1400×3/1500）：肋骨系列/合成器官/脑激励器/AI 芯片
- 义肢制造 IV → VII（2000/2500/1500/1500）→ 器官培养舱/人造器官组装台

### 5. 毒品链（太空段）
- 毒品 VII（1500，[原版] PsychiteRefining）→ 灵能结晶/灵能粉/灵能茶/战斗鸡尾酒
- → 毒品 VIII（2000，交叉前置：高级零件）→ 高级药物合成台 → 高级灵能茶
- → 毒品 IX（2500，交叉前置：医疗物资 VI）→ 纳米修复针

### 6. 护盾链
- 充能技术（1500）→ 充能台 → 充能护盾腰带 → 充能增效（2000）→ 充能效率模块
- 部署式护盾（2000，[原版] ShieldBelt）→ 部署式护盾发生器
- 灵能护盾（2500）→ 灵能护盾腰带
