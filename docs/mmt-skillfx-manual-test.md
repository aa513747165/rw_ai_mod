# MMT 技能特效框架 · 手动测试文档

面向游戏内实测，覆盖框架第一~二十三步全部功能。37 个演示技能集中在**演示技能集**（`MMT_SkillDemoSet`），经 Dev Debug 一键赋予任意小人后实测；**沙袋人偶（友方/敌方）只作敌我靶子，不再携带技能**。演示 gizmo **仅在开发者模式（Dev Mode）下显示**。

- 代码：`Source/MyModeTest/SkillFX/AbilityTargeting.cs`、`CastBar.cs`、`SkillShooting.cs`、`SkillBeam.cs`（含引导占用）、`SkillStrike.cs`、`SkillGroundFire.cs`、`SkillAura.cs`、`SkillBuffFX.cs`、`SkillDisplace.cs`、`SkillSummon.cs`、`SkillDelayedStrike.cs`、`SkillKnockback.cs`、`SkillChainLightning.cs`、`SkillBreath.cs`、`SkillHeal.cs`、`SkillWall.cs`、`SkillGroundZone.cs`、`SkillTrap.cs`
- Def：`1.7/Defs/Misc/MMT_SkillDemoSet.xml`（37 条演示唯一数据源）、`1.7/Defs/ThingDefs_Buildings/MMT_Buildings_TrainingDummy.xml`（敌我靶子）、`MMT_SummonEntities.xml`、`MMT_Buildings_SummonTurret.xml`、`MMT_Hediffs_Summon.xml`、`MMT_DelayedStrike.xml`、`MMT_ChainArc.xml`、`MMT_BreathCone.xml`、`MMT_MagicStoneWall.xml`、`MMT_Projectiles_SkillDemo.xml`（大火球）、`MMT_Jobs.xml`（引导作业）、`MMT_GroundZone.xml`（持续地面区域）、`MMT_SkillMine.xml`（爆炸陷阱）、`MMT_NovaRing.xml`（新星环）等

## 0. 测试前准备

1. 开始/读取一个存档，开启**开发者模式**（选项 → 开发者模式）。
2. 建造一个**沙袋人偶**（建筑菜单 → 娱乐，造价 40 土 + 20 布 + 10 木）。
3. 开启 Dev 模式后，建筑菜单 → 娱乐中会多出一个**沙袋人偶（敌方）**（造价 0），放下 1~2 个。放下后应立即归属远古敌对派系（选中查看派系不是玩家殖民地）。
4. 建议再准备：2~3 名殖民者站在假人旁、1 只驯服动物，便于观察敌我判定与群体效果。
5. 沙袋人偶只是靶子：选中它**不会**出现技能 gizmo，只有承伤统计与清零按钮。

### 0.1 一键把演示技能赋予小人（唯一入口）

整套 37 个演示技能经 Dev Debug 挂到小人身上实测：

1. Dev 工具栏（上方工具图标）→ **Debug Actions** → 分类 **MMT 技能** → **赋予全部演示技能（选中小人）**。
2. 鼠标变为选中小人模式，点击一名殖民者 → 提示「已赋予 XXX 全部演示技能（37 个）」。
3. 选中该小人，gizmo 栏出现 37 个「测试·XXX」按钮；读条圆画在小人头顶（高 0.75 格）。
4. 同菜单下 **移除演示技能（选中小人）** 可收回。
5. **注意**：comp 为运行时注入，原版存档/读档后注入的 comp 不保留，读档后需重新一键赋予（这是已知行为，非 Bug）。

下文所有「施法者」均指被赋予技能的小人；假人只作为敌我靶子承接技能。

**通用预期**：所有演示技能施放后都会在屏幕左上角弹消息提示（如「【测试·单发火球术】发射！」）。若 gizmo 不出现，先确认 Dev 模式已开且小人已被赋予技能。

## 1. 范围圆形选择框（敌我判定）

对应演示：**测试·友方回响**、**测试·敌方回响**（均半径 5，无读条瞬发）。

| 序号 | 操作 | 预期结果 |
|---|---|---|
| 1.1 | 点「测试·友方回响」，移动鼠标 | 鼠标位置出现**绿色**圆形范围框（贴图圆，非方形），以鼠标为中心随动 |
| 1.2 | 友方回响选框扫过殖民者/友方假人 | 范围内**友方**目标高亮；敌方假人不高亮 |
| 1.3 | 点击释放友方回响 | 左上角消息「【测试·友方回响】将影响 N 名友方：xxx、yyy」，名单与实际范围内友方一致 |
| 1.4 | 点「测试·敌方回响」，扫过敌方假人 | 圆形选框为**红色**；只有敌方假人高亮，友方不高亮 |
| 1.5 | 释放敌方回响 | 消息显示「N 名敌方」及名单 |
| 1.6 | 右键/Esc 取消选框 | 选框消失，无消息、无副作用 |
| 1.7 | 关闭 Dev 模式再选中已赋予技能的小人 | 所有「测试·」gizmo 消失（框架 gizmo 为 Dev 限定） |

**回归点**：圆形选框应为贴图圆（`Things/Mote/MMT_TargetCircle`），边缘平滑；若显示为方形网格或纯色块说明贴图未加载。

### 4A. 引导占用（第十四步：持续期间不能做其它事）

| 序号 | 操作 | 预期结果 |
|---|---|---|
| 4A.1 | 烈焰射线展开后观察施法小人 | 小人进入**引导状态**（原地站立、面朝射线方向，工作标签显示「正在引导技能」），不能自动去做其它事 |
| 4A.2 | 引导中右键命令小人**移动** | 射线**立刻中断消失**，消息「持续射线被打断！」，小人执行移动 |
| 4A.3 | 引导中对同一小人在 gizmo 栏点**另一个演示技能** | 旧射线立即断线（同样提示打断），新技能正常进入瞄准/读条 |
| 4A.4 | 引导中小人被击晕/倒地（Dev 伤害） | 射线立即消失 |
| 4A.5 | 不打扰引导，4s 自然结束 | 射线消失后小人恢复正常可指挥状态，无残留「引导中」卡死 |

对应演示：**测试·落雷**（单体锁定，1.5s，伤害 20）、**测试·雷暴**（半径 5 范围，3s，8 次打击、间隔 12 tick、单次 10）。

## 9. 位移效果（折跃 / 群体传送 / 冲锋 / 跳跃）

对应演示：**测试·折跃**（射程 10，0.5s）、**测试·群体传送**（半径 4 选敌 + 二次指定落点，射程 24.9，1.5s）、**测试·冲锋**（射程 15，0.5s，1.5 tick/格）、**测试·跳跃**（射程 20，0.5s，峰值高度 3）。

> 注意：折跃/冲锋/跳跃的位移对象就是**施法小人自己**（pawn 走原版飞行/移动逻辑；框架对建筑也通用，由位移载体搬运）。群体传送的被传送对象是**第一段圈选框住的目标**。

| 序号 | 操作 | 预期结果 |
|---|---|---|
| 9.1 | 折跃：指定技能范围内一格 | 读条 0.5s 后施法者**瞬移**到目标格，原地与落点各闪一次折跃特效（`MMT_BlinkFlash`），消息「折跃！」 |
| 9.2 | 折跃落点不可站立（墙/深水） | 消息「落点不可站立，位移取消」，不发生位移 |
| 9.3 | 群体传送：第一次框选范围（半径 4）内敌方 | 确认后出现**第二次**指定落点的选框，消息「请指定传送落点」 |
| 9.4 | 群体传送：指定落点后 | 被框的所有有效目标**集体瞬移**到落点（各自附近找站立格），每个目标带折跃特效，消息「已传送 N 个目标！」 |
| 9.5 | 冲锋：指定范围内位置 | 施法者以**快速平移**方式（带冲锋拖尾特效 `MMT_DashTrail`）沿直线冲到目标点，速度明显快于奔跑 |
| 9.6 | 冲锋路径被阻挡 | 停在可达最近格，不卡死、不报错 |
| 9.7 | 跳跃：指定范围内位置 | 施法者**先升空后降落**（复用原版 PawnFlyer 飞行逻辑，抛物线顶点约 3 格高），落地有落点特效 |
| 9.8 | 跳跃越障 | 可越过矮墙/围栏等跳跃可越障碍（与原版跳跃包一致） |

## 10. 召唤效果（雷球 / 追踪弹 / 动物 / 炮塔）

对应演示：**测试·雷球**（1.5s，射程 15）、**测试·追踪弹**（1s，射程 20，8s 持续）、**测试·动物召唤**（1s，哈士奇 20s）、**测试·炮塔召唤**（2s，射程 12，40s）。

### 10.1 雷球（无敌不可选中 · 缓慢推进 · 沿途脉冲）

| 序号 | 操作 | 预期结果 |
|---|---|---|
| 10.1.1 | 指定技能范围内一格释放 | 读条 1.5s 后**从施法小人位置**生成雷球（蓝白核心贴图，呼吸缩放 + 自转 + 辉光），消息「雷球出击！」 |
| 10.1.2 | 观察移动 | 雷球以约 15 tick/格的速度**匀速滑向**目标格（缓慢、可肉眼跟随） |
| 10.1.3 | 脉冲伤害 | 行进途中每 20 tick 对雷球**当前位置周围 2.5 格内敌方**造成 8 点伤害（途经的敌方假人承伤统计上涨） |
| 10.1.4 | 不可选中 | 点击雷球无法选中，框选/攻击指令打不到它（无敌、无血条） |
| 10.1.5 | 到达目标格 | 雷球播放消散特效后消失，不残留 |

### 10.2 追踪弹（无敌 · 锁定追踪 · 限时）

| 序号 | 操作 | 预期结果 |
|---|---|---|
| 10.2.1 | 点选一名**敌方 pawn**（不能点地板、不能点友方） | 选框只允许锁敌方 pawn；读条 1s 后从施法小人射出追踪弹（弹头贴图朝飞行方向旋转），消息「追踪弹发射！」 |
| 10.2.2 | 目标移动 | 追踪弹每 tick 修正航向**持续咬住**目标（约 5 tick/格） |
| 10.2.3 | 命中 | 接触目标后爆炸（半径 1.5，伤害 20）并消失 |
| 10.2.4 | 目标中途死亡/消失 | 追踪弹播放消散特效自行消失，不报错 |

## 24. 已知设计行为（非 Bug）

- 读条圆为满圆顺时针消减；瞬发技能（castSeconds=0）无读条。

- 召唤炮塔通过 `CompLifespan` 年龄偏移实现自定义 40s 寿命，到期即毁不爆残骸。
- 持续射线（及后续引导类技能）在引导期间占用施法者：**移动/下令/施放其它技能/被击晕**都会立即断线，这是第十四步的设计要求，不是 Bug。
- 引导状态由专用引导作业（`MMT_ChannelSkill`）+ 忙碌姿态实现；读档后作业不恢复，射线读档即自毁（特效最长数秒，可接受）。
- 延时打击的预警调度器/陨石、连锁闪电电弧、龙息吐息均为运行时特效实体，**读档后自毁**（陨石读档后立即引爆兜底）。
- 龙息**不分敌我**（锥内谁都烧），演示时注意友方站位。
- 大火球无视视线属设计（抛物线跨墙），瞄准则仍受 30 格射程限制。

- 驱散/净化**只移除有持续时间的状态**（带 HediffComp_Disappears 的限时 Hediff，如迅捷祝福/迟缓诅咒）；伤疤、植入体、成瘾、慢性病等永久/无时限状态永远不可驱散，这是第二十三步的核心约束，不是遗漏。驱散本身为一次性即时结算，无可存档状态。
