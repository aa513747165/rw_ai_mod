# MMT 终局内容包 — 贴图生成说明（AI 出图用）

> 用途：把本文档中每个条目的「画面描述」喂给图像生成 AI，产出 PNG 后按下述「落盘规格」裁剪/命名，放入 `1.7/Textures/` 对应路径。
> 当前目录下已有程序生成的占位贴图，AI 出图后**直接覆盖同名文件**即可，Def 引用无需改动。

## 一、全局风格要求（每张图都适用）

- **游戏**：RimWorld（环世界）风格，**正俯视视角**（top-down），可见物体顶面 + 朝南的侧面，光源在上方偏左。
- **绘制感**：粗深色描边（近黑但带一点色相，如 `#1a1410`，不要用纯黑）、2~3 阶明暗块面、柔和手绘填色、可带轻微噪点。
- **配色**：低饱和、偏大地色系；金属偏冷灰蓝，高科技部件允许小面积能量色点缀（青蓝/紫），禁止大面积高饱和霓虹。
- **背景**：纯透明（RGBA），物体内容约占画布 60~80%，四周留透明边。
- **禁止**：照片级渐变、锐利矢量感、文字/字母入图、透视倾斜（不要 45° 等轴测）。
- **遮罩（`_m` 图）**：与主图同尺寸同构图，纯黑白灰+红绿通道图——红色区域会被游戏染成主材质色、绿色=次要色、**纯黑=不染**。AI 出图只出主图即可，遮罩由工具从主图生成（或直接全黑）。

## 二、建筑贴图

建筑贴图尺寸 = 128 × 格数。多朝向建筑需 3 张：`south`（正面，基准图）、`east`（右侧面视角）、`north`（背面，可减细节）；三者是**同一物体的不同朝向**，不是简单翻转。

## 五、落盘与验收（AI 出图后执行）

1. 裁剪/缩放到指定尺寸（PNG，RGBA 透明底）。
2. 按上述路径覆盖同名文件；多朝向以 south 为基准派生 east/north。
3. 遮罩 `_m` 由工具生成（默认全黑，无需染色）。
4. 验证：`python tools/validate_new.py all`（含贴图存在性检查）+ 游戏内目检。
5. 同步游戏目录：`MSYS2_ARG_CONV_EXCL='*' robocopy H:/rw "D:/SteamLibrary/steamapps/common/RimWorld/Mods/rw" /MIR /XD .git Hardcore-SK 汉化 docs tools data .superpowers Source ...`（见日常同步命令）。

**贴图清单合计**：建筑 4 组（强化台 3 + 扫描仪 3 + 阻尼器 3 + 奇观 4×1 + 辉光 1 = 14 张）+ 物品 21 张（资源 3 + 淬火油 1 + 模块 17）+ 世界图标 3 张 = **39 张主图**（遮罩另计、工具生成）。
