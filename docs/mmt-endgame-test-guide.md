# MMT 终局内容包 测试文档

> 手工维护。对应设计文档 `docs/mmt-endgame-design.md`，本文档面向测试：每个功能的**触发方式、预期表现、dev 快捷验证路径**。

- 同步目录：`D:\SteamLibrary\steamapps\common\RimWorld\Mods\rw`（已由 robocopy 镜像 1.7 全目录）。
- 开发模式：主菜单 → 选项 → 打开开发者模式；进图后用 Debug Actions（闪电图标）刷资源/研究。

- 自动校验基线：`python tools/validate_mod.py all` + `python tools/validate_new.py all` 全绿（已实现套件：settings / weaponenhance / exploration / storm / wonder + 旧套件回归）。

## 1. Mod 设置面板

**入口**：主菜单 → 选项 → Mod 设置 → "MMT 资源生产"（单页滚动）。

| 分组 | 设置项 | 默认 | 验证方法 |
|---|---|---|---|
| 资源与研究 | 资源产率倍率 ×0.5–3.0 | 1.0 | 调到 2.0 → 任意 MMT 配方（如玻璃）完成时产出数量翻倍；恢复 1.0 复原 |
| 资源与研究 | 研究成本倍率 ×0.25–2.0 | 1.0 | 调到 0.25 → 研究界面 MMT 项目所需点数变为 1/4 |
| 强化与装备 | 强化成功率倍率 ×0.5–2.0 | 1.0 | 调到 2.0 → 护盾/武器强化菜单显示成功率翻倍（封顶 100%） |
| 强化与装备 | 仅限 MMT/原版装备强化 | 关 | 勾选后其它 mod 武器无法装入强化台；非 MMT 护盾不出强化菜单 |
| 传送 | 传送次数上限加成 0–9 | 0 | 调到 3 → 传送台次数上限 +3（检查面板可见） |
| 爆墙炸弹 | 总开关 / 财富门槛 5万–50万 / 概率倍率 0–3 | 开 / 10万 / 1.0 | 见 §6 |
| 事件开关 | 能量风暴+频率、电磁脉冲日、陨石雨、精英爆破手、黑市中间人、赏金任务、据点生成、奇观超载事故（默认关）、奇观周年庆典 | 见面板 | 事件类开关关闭后对应机制不触发（能量风暴/据点生成本次已实现，其余为后续条目预留开关位） |

- 底部"恢复默认设置"按钮一键还原。
- 读档/重启游戏后设置保持。

## 2. 武器强化台（赌博线强化 + 确定线附魔）

**解锁**：研究"武器强化"（4000 点）→ 建造 MMT 生产 → 武器强化台（2×2，强化玻璃×80、机器人部件×20、碳合金×40、微芯片×4，1500W）。

**操作流程**：殖民者右键强化台 →"装载武器"（从主手/背包选择）→ 台内武器飘浮显示 → 右键"强化武器"/"附魔武器" → 完成后"取出武器"。

### 2.1 强化（赌博线，+1 ~ +15）

- **效果**：每级伤害 ×1.05（复利，满级 ≈×2.08）；+15 满级额外护甲穿透 +10%。武器标签追加 "+N"，检查面板显示伤害倍率。
- **成功率**：1-3 级 100%、4-6 级 80%、7-9 级 60%、10-12 级 40%、13-14 级 20%、15 级 5%（×设置倍率）。
- **材料阶梯**（与护盾强化共用，每次强化按目标等级收取）：

| 目标等级 | 材料 | 来源 |
|---|---|---|
| +1~+3 | 能量结晶 ×目标等级 | 自产（晶体培养舱） |
| +4~+6 | 能量结晶 ×目标等级 + 钨/钛 ×2（任一） | 自产 |
| +7~+9 | 能量结晶×5 + 远古合金×3 | 探索据点/任务 |
| +10~+12 | 能量结晶×8 + 远古碎晶×2 | 探索据点/任务 |
| +13~+15 | 能量结晶×10 + 远古碎晶×3 + 远古数据核心×1 | 机械据点/任务 |

- **失败**：只损失材料，武器不掉级、不损坏。
- **dev 验证**：Debug 刷能量结晶 → 装步枪连点强化到 +3（必成），看伤害 inspect 上浮与 "+3" 后缀；材料不足时菜单置灰显示缺口。

### 2.2 附魔（确定线，100% 成功）

- **槽位**：基础 1 槽；强化 +7 解锁第 2 槽、+13 解锁第 3 槽；同词条不可重复。
- **流程**：强化台配方制作附魔模块（消耗档位材料）→ 模块放地图储存区或小人背包 → 右键强化台"附魔武器" → 选模块 → 小人取模块安装。

| 档位 | 材料 | 词条（效果） |
|---|---|---|
| 低级 | 淬火油×2 + 能量结晶×3 | 锋利（伤害+8%)、精准（命中+8%)、轻巧（冷却-8%)、穿透（穿甲+15%) |
| 中级 | 淬火油×3 + 钛×8 | 致命（暴击率+5%，暴击×2)、疾风（冷却-12%+瞄准-20%)、重击（伤害+12%+近战击退）、速射（冷却-15%命中-4%) |
| 高级 | 淬火油×4 + 远古合金×10 | EMP弹（对机械×1.5+短路）、燃烧弹（命中点燃）、吸血（近战5%转治疗）、破盾（护盾拦截额外消耗+50%)、冰霜（命中减速20%×3秒） |
| 极品 | 淬火油×5 + 远古碎晶×5 + 数据核心×1 | 处决（目标血量<20%时×2)、连锁闪电（弹射2格50%)、时空折叠（击杀冷却归零）、过载（伤害+25%冷却+15%) |

- **淬火油**：石化产品实验室配方"调配淬火油"（兽脂×5 + 氧化化合燃料×2 → 3 份，需研究"武器附魔"）。
- **dev 验证**：刷材料做"锋利模块"→ 附魔 → 检查面板出现词条；攻击假人/敌人看伤害上浮与特效（燃烧/冰霜减速/暴击飘字等）。

### 2.3 跨 Mod 兼容

- 强化 comp 挂在全体带 weaponTags 的武器（含其它 mod）：其它 mod 武器可直接装入强化台。
- 设置"仅限 MMT/原版装备强化"勾选后，非 MMT/原版武器不开放强化。
- **CE 共存**：远程弹道被 CE 重写时远程强化可能失效（代码已检测 CE 存在）；近战线不受影响。

### 2.4 护盾强化变化

- MMT 护盾（充能台强化）：材料改为同一阶梯（+7 起需远古材料），成功率 × 设置倍率；旧存档无阶梯配置时回退旧单材料行为。
- 非 MMT 护盾（原版/其它 mod 带能量护盾的服装）：可在充能台装载强化，**只加护盾值（每级上限 +8%）与恢复效率（每级 +6%）**，满级 ×2.2 / ×1.9。
- **验证**：原版护盾腰带上充能台强化 +2，检查面板护盾能量上限 ×1.16。

## 3. 世界探索：深空扫描仪

**解锁**：研究"深空扫描"（8000 点，前置折跃传送）→ 建造 3×3 扫描仪（Steel×150、声纳模块×10、太空零件×6、金×20，3000W）。

**流程**：
1. 扫描仪自动蓄电（30000 Wd 上限，3000/天）；充满后 gizmo"启动深空扫描"可用（还需地图上有 1 个矿物声纳模块）。
2. 启动 → 清空蓄电 + 消耗声纳模块 → 扫描 1 天（装超频模块提速 +10%/个，最多 5）。
3. 完成 → 收信"深空扫描完成"→ 世界地图出现据点（距家 6-30 格，30 天过期）。
4. 传送台折跃小队进入 → 战斗/拾取 → 召回；站点取空/过期自动回收。

**据点类型**（守卫用原版休眠机械群，不惊动不主动攻击）：

| 据点 | 权重 | 守卫 | 奖励堆 |
|---|---|---|---|
| 稀有资源点 | 45% | 轻（威胁×0.5） | 远古合金×15-25 + 太空零件×2-4 |
| 轨道遗迹 | 35% | 机械集群 | 远古碎晶×6-10 + 远古合金×5 + 太空零件×3-6 |
| 机械据点 | 20% | 大机械集群（威胁×1.6） | 远古碎晶×8-12 + 数据核心×1 + 远古合金×4-8 |

- 奖励堆在据点中心附近，沙袋围圈标记。
- **设置开关**："深空扫描据点生成"关闭后无法启动扫描。
- **dev 验证**：Dev→Spawn thing 充满蓄电（或 dev 建好后等待）；触发扫描后 dev 快进 1 天收信；传送台折跃进入验证休眠机械唤醒逻辑为原版行为。

## 4. 终局奇观：纪元奇点

**解锁**：研究"奇点工程"（20000 点，前置物质转换 III + 能量聚能）→ 建造"奇点地基"（5×5，**必须露天**）。

**四阶段推进**（每阶段建成后，建筑上出现 gizmo"开始下一阶段建设"，点击落下一阶段蓝图、造价另付）：

| 阶段 | 造价 | 工作量 |
|---|---|---|
| 一 奇点地基 | 土堆×2000、混凝土×400、钢铁×300 | 15000 |
| 二 奇点框架 | 强化玻璃×300、金属罐×200、碳合金×150、金×50 | 20000 |
| 三 奇点核心 | 反物质×10、α聚合物×100、机器人部件×60、远古合金×80、太空零件×20 | 30000 |
| 四 纪元奇点 | 氧化化合燃料×400、远古碎晶×30、绘画用品×50、铀×100 | 20000 |

**激活**（终态建筑）：加注反物质燃料满（×5，5000W 电网回充蓄电 50000 Wd）→ gizmo"启动奇点"→ 点火倒计时（约 2 小时，紫光盘柱特效）→ 三选一弹窗 → 本图永久增益：

| 选项 | 效果 |
|---|---|
| 能源纪元 | 全图发电建筑输出 ×1.25 |
| 启迪纪元 | 殖民者研究 +25%、全局工作速度 +10%（hediff 周期性刷新） |
| 丰饶纪元 | 植物生长速度 ×1.5 |

- 每张地图独立（增益不跨图）；激活为一次性。
- **dev 验证**：dev god mode 速建四阶段 → dev 刷反物质加注 → dev 充满蓄电 → 点火快进 → 弹窗三选一 → 对应增益生效（发电数值/hediff/植物 inspect）。

## 5. 能量风暴（后期威胁）

**触发**：财富 ≥20 万的玩家基地，基础权重 2.0、最短间隔 20 天、游戏 60 天后（频率 × 设置倍率；总开关可关）。

**效果**（持续 1-2 天）：
- 太阳能/风能输出 ×0；
- 每游戏 1 小时随机点名 1-3 个未防护电子设备：触发故障 + MMT 蓄电建筑放电 25%（短路火花特效）；
- 风暴阻尼器（研究"风暴防护"解锁，2×2，强化玻璃×40+金×15，800W）半径 12 格内建筑免疫点名。

**dev 验证**：Dev→触发事件 MMT_Incident_EnergyStorm → 太阳能归零（检查面板）、未防护建筑逐小时故障；阻尼器半径内建筑无故障。

## 6. 爆墙炸弹设置化（既有功能接入）

- 设置面板"爆墙炸弹"分组：总开关 / 财富门槛（默认 10 万，封顶=门槛×10）/ 概率倍率（0-3，0=不出现）。
- **验证**：财富 10 万+ 袭击中观察携带者出现率随倍率变化；总开关关闭后袭击者不再携带。

## 7. 已知边界与注意事项

- 据点过期（30 天）后自然消失，进行中的据点不受设置开关影响（开关只拦新生成）。
- 时空折叠"冷却归零"通过取消冷却姿态实现，连杀机枪塔不适用（只对小人手持武器）。
- 能量风暴期间 MMT 护盾系建筑可被点名（不属白名单）——用阻尼器保护。
- CE 共存时远程强化数值可能失效（见 §2.3）。
- 性能：全部周期逻辑走 CompTickInterval/2500 tick 间隔；伤害补丁只在开火/命中时触发；无逐 tick 全图扫描。
