# MMT 天赋树系统（历练 × 职业深度绑定）v1.0

> 本文是天赋树系统的全览手册（设计 + 数值 + 操作 + 管线）。
> 变更溯源见 `docs/mmt-class-design.md` §9；实现参照 Isekai RPG Leveling（workshop 3657580708，贴图已获授权，代码仅作参考不复制）。

## 1. 体系总览

```
打伤害/击杀/工作/社交/灵能/贸易…（全源经验，TalentXPPatches.cs）
        ↓
历练等级 1-60（XP 曲线 100×N^1.5，CompPawnProgress）
        ↓ 每级 +1 天赋点（共约 59 点 + 任务/道具）
┌──────────────────┐
│ 通用天赋树（59 节点）│  战斗 / 灵能 / 生产 / 生存 / 社交 五支
│ 19 个旧 perk 已并入  │
└────────┬─────────┘
         ↓ 支路末端：10 个「道」之 Keystone（ClassUnlock，3 点）
   解锁职业家族就职资格（写入 unlockedFamilies）
         ↓
职业导师台 + 职业凭证×1（凭证来源：A 级以上公会委托 / Dev）
         ↓ 就职（历练≥5，无灵能者自动觉醒）
┌──────────────────┐
│ 本职业家族树（~38 节点）│ Start 免费解锁
│ 主干被动 → 职业技能链 → 强化节点 → 家族 Keystone
└──────────────────┘
         ↓ 升 II 阶（历练≥20+结晶×10）/ III 阶（≥35+×20）
   解锁该阶技能节点（requireTier 门控）
```

核心规则：
- 每人限 1 职业（v1 不做转职）；家族树只对已就职小人开放，且只能点本职业的技能簇。
- 天赋点总量刻意小于全树总花费（通用 59 节点约 75 点 + 家族树约 60 点），加点即取舍。
- 节点效果两类：**被动**（解锁即挂 Hediff，吃原版 stat 缓存）与**技能**（直接 `GainAbility` 出 gizmo，耗灵能熵/集中）。

## 2. 通用天赋树（MMT_TalentTree_General，59 节点）

五支从中心「历练启蒙」（0 费）放射；19 个旧 perk 原 Hediff 不变地并入对应支路。

| 支路 | 方向 | 内容 | 末端职业解锁 |
|---|---|---|---|
| 战斗 | 东 | 6 旧 perk（老兵/近战大师/坚韧/神行/快速恢复/战斗直觉）+ 5 小点 | 剑刃之道、神射之道、先锋之道 |
| 灵能 | 北 | 熵上限/熵恢复/灵能敏感度/冥想 11 点 | 死灵/元素/奥秘/圣光/自然/心灵 六道 |
| 生产 | 西 | 7 旧 perk（巧手/矿工/农夫/建筑工/学者/厨师 + 大师品质 Keystone 2 点）+ 4 小点 | — |
| 生存 | 南 | 6 旧 perk（铁躯/高效肠胃/熟睡/心墙/坚韧意志/驮兽）+ 4 小点 | 战辅之道 |
| 社交 | 西北 | 社交/贸易/谈判/驯兽/逮捕 5 点 | — |

## 3. 职业家族树（10 棵，共 378 节点）

37 职业分 10 家族（分组维护在 `mmt_rom_class_mapping.json` classes 段 `family` 字段）：

| 家族 | 成员职业 |
|---|---|
| 元素 elemental | 火系魔法师、冰系魔法师、雷系魔法师、地占师、气象法师 |
| 奥秘 arcane | 奥术法师、附魔师、时空法师、技法师、流浪法师 |
| 死灵 necro | 死灵法师、血法师、恶魔术士、附身灵 |
| 圣光 holy | 牧师、圣骑士、光法师 |
| 自然 nature | 德鲁伊、萨满、召唤师、傀儡师 |
| 心灵 mind | 吟游诗人、共情者、暗影 |
| 剑刃 blade | 刀锋舞者、角斗士、武僧 |
| 先锋 vanguard | 死亡骑士、超级士兵、灵能武者 |
| 神射 marksman | 游侠、狙击手、无面者 |
| 战辅 support | 指挥官、药剂师、战地军医、旅者 |

每棵树结构（自动布局：主干上行、职业簇下半圆扇形展开）：

- **Start**（0 费）：就职时自动解锁。
- **主干 5 点 + Keystone（3 点）**：家族主题被动（stat Hediff，如元素=灵能敏感度/熵上限、剑刃=近战命中/闪避）。
- **职业技能簇**（每职业一支，`classBaseName` 限定）：
  - 职业印记（1 点，小被动）→ 技能链（按映射表顺序，花费=技能 stage 1/2/3，`requireTier`=stage，即 II 阶技能需已升 II 阶）→ 强化节点 ×2（2/3 点，需 II/III 阶，主题为熵恢复/熵上限+职业向小加成）。

## 5. 公会狩猎委托

- **生成**：`GameComponent_GuildQuests` 按间隔（默认 1 天，设置 0.5-5）发委托；段位 F-SSS 按全殖民者历练水平（有效等级 = max(平均, 最高×0.75)）+ 财富（每 25 万 +1 上限）加权。
- **形态**：F-E 1 只 / D-C 2 只，本地图边缘刷敌对生物；B 4 只 / A 6 只，世界站点群猎（2-8 格，`MMT_SitePart_GuildHunt`，15 天过期）；S-SSS 站点单 Boss（combatPower ≥220）。
- **据点联动**：世界委托（B 级以上）生成时优先挂到**深空扫描仪已发现但未被清剿的据点**（副本/轨道遗迹/机械据点/Boss 巢穴等，要求有敌对派系宿主或机械集群守卫、未被其它委托占用，多个取距家最近者）。清剿该据点即完成委托——据点战利品照拿，公会另付委托报酬（双份收益）。完成检测：据点图上观察到敌对威胁后威胁全清 → 完成；站点消失时按是否见过敌对威胁区分"已清剿被移除"（成功）与"超时消失"（失败）。
- **委托直建新副本**：无既有据点可挂载时，按设置项**委托直建新副本概率**（默认 35%，0-100%）直接生成一处新据点——与深空扫描同池同威胁公式（`DungeonSiteGen.GenerateRandomSite`，仅抽有守卫条目），段位映射档位（B→I / A→II / S 以上→III）；之后按据点联动同一套规则判定完成。未抽中或生成失败时回退自建狩猎场。
- **期限**：本地 7 天 / 世界 14 天，超时判负（已刷出的怪不清除）。
- **奖励**（完成时发）：XP `60×2^段位`（60→15360，战斗图殖民者均分）+ 白银 `50×1.8^段位`（50→5510）空投；B 级以上附能量结晶 2-6；**A 级以上附职业凭证×1**（凭证的正式游戏内来源）。
- 敌对化：动物上永久猎杀状态，虫类挂虫族派系；选怪按 combatPower 区间，排除 Dryad 类。

## 6. UI 操作（天赋树窗口）

入口：历练页签「打开天赋树」按钮，或有可用点时的 gizmo。

- 左侧页签切换 通用树 / 本职业家族树；中间画布 **右键拖拽平移、滚轮朝鼠标缩放（0.35-2.0）**；
- **单击**节点看详情（效果/花费/前置），**双击**加点——深层节点自动沿最短路径链式解锁（逐节点过门禁，总价不够则提示）；
- 连线三态：金=两端已解锁、灰亮=一端可达、暗=锁定；节点形状：圆=小点、大圆=重要/技能、菱形=基石/职业解锁、星形=起点；
- 洗点 v1 无 UI，仅 Debug「天赋全退」。

## 7. 存档与迁移

存档字段（CompPawnProgress，全部带默认值）：`talentPoints`、`unlockedTalents`（"tree:node"）、`unlockedFamilies`、`perkMigrated`。

旧档迁移（幂等，读档/生成时各一次）：
1. 旧 `perks` 列表按映射补登记为通用树节点（Hediff 已在身上，不扣点）；
2. 剩余 perk 点 1:1 转天赋点；
3. 已就职小人按当前阶位免费补发家族树 Start + 全部应得技能节点（阶位 Hediff 去 abilities 后技能不丢）。

## 8. 管线与校验

| 项 | 位置 |
|---|---|
| 人工维护点 | `tools/data/mmt_talent_tree_mapping.json`（通用树布局/家族主题）+ `mmt_rom_class_mapping.json`（classes.family 分组、abilities） |
| 生成器 | `tools/build_mmt_talent_trees.py`（`--check` 幂等校验） |
| 生成物 | `1.7/Defs/TalentDefs/MMT_Talents_{General,Families}.xml`、`1.7/Defs/HediffDefs/MMT_Hediffs_Talents.xml`、`1.7/Textures/UI/TalentTree/`（Isekai 授权贴图 44 张） |
| 校验套件 | `tools/validate/talent_tree.py`（图连通/唯一 Start/cost 规则/家族覆盖/技能 requireTier=stage/stat 白名单/贴图/C# 接线） |

改动流程：改映射 JSON → 重跑生成器 → `python tools/validate_new.py talent_tree` → `dotnet build`。**不要手改生成物 XML。**

## 9. 调参与 Debug

- 设置面板（MMT 资源生产 → 历练/职业）：XP 倍率、公会委托开关、委托间隔、XP 飘字、光环脉冲间隔。
- Debug 菜单「MMT 职业」：天赋点 +10 / 天赋全退 / 解锁全部职业家族 / 发放职业凭证 / 生成公会狩猎委托。

## 10. 已知边界与后续

- 技能强化节点为主题被动（熵/恢复向），**真升级变体**（强化版技能替换）未做；
- 洗点 UI、精英词缀、称号决斗、法力核心掉落未做（Isekai 特性，非本系统目标）；
- 公会委托为自动接受制（无拒绝按钮）；
- 家族树布局为生成器自动扇形排布，如需美术级手排可在映射 JSON 扩展坐标覆盖；
- 游戏内手测路径见 `mmt-class-design.md` §9.8。
